### Regras gerais pro grupo

1. Rotas: Nome sempre em português, sem acentuação, todo conteúdo dos scripts devem ser em inglês.
2. CSS usado repetidas vezes deve ser colocado no final do arquivo [CSS - Common](src/routes/common.css) como uma classe utilitária com o nome mais curto e auto-descritivo possível.
3. Antes de commitar qualquer coisa, use o comando `npm run format` (isso executa o lint configurado no arquivo `prettier.config.js`).

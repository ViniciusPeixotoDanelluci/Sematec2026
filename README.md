## Sematec2026

**Projeto em grupo para a Sematec do segundo semestre de 2026**

## Instalação

1. Rode `npm install` no terminal do projeto e ele vai ser instalado automaticamente.
2. Crie um arquivo chamado `local.db` na pasta raiz do projeto.
3. Crie um arquivo `.env` baseado no arquivo `.env.example`.
4. Instale a extensão [SQlite](https://marketplace.visualstudio.com/items?itemName=alexcvzz.vscode-sqlite) caso esteja no VSCode para poder visualizar a Database.
5. Use o comando `ctrl + shift + p` e digite "SQLIte: Open Database".
6. Rode o comando `npm run db:setup` ou `NODE_ENV=development npm run db:setup` e em seguida `npm run dev` para executar o App.
